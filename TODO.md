3. Add an x86_64 installation test. `make test` runs only on the arm64 host, so amd64-only failures go unnoticed: the csvq amd64 release binary needs GLIBC 2.34 and failed on Oracle Linux 8 (2.28) while every test passed. `verify_installation` only checks that the command exists, so a binary that cannot start still passes; `list.sh` catches it only on the tested architecture. A manual check works on a host with qemu-user-binfmt: `docker build --platform linux/amd64 --build-arg BASE_IMAGE=oraclelinux:8 .` and run the container as root, because setuid `sudo` does not work under the emulator (binfmt flags lack `C`). Emulated builds take over ten minutes, so consider a target limited to the tools with per-architecture branches (`git grep -n 'uname -m' scripts/`) rather than `provision.sh all`.
